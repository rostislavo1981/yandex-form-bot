# 15. Группа, кнопки и расписание

## Обязательное условие

Все ответственные находятся в одной группе. Бот — администратор с минимальными правами `write` и `pin_message`.

## Видимые кнопки

Групповой пульт закреплён. Личный пульт отправляется на `/start`, `/menu`, после отчёта и после действий. Основной сценарий не требует знания slash-команд.

## Карточка отчёта

Создаётся через transactional outbox и публикуется только после commit. Содержит дату, объект, этап, ФИО и короткие суммы. Повторная публикация ограничивается ключом `report:{report_id}:{group_id}`; временные ошибки MAX повторяются worker.

## Расписание

Время хранится в `max_groups`, timezone по умолчанию `Europe/Moscow`.

- начало дня: создать obligations;
- вечернее напоминание №1;
- вечернее напоминание №2 только если pending остались;
- утро следующего дня: pending → missed и итог previous day.

## Счётчики

`expected` — число obligations; `submitted` включает вовремя отправленные; `late` показывается отдельно; `missing` — pending/missed. Если человек ведёт три объекта, это три ожидаемых отчёта.

## Идемпотентность

Каждая задача имеет notification key. Перед отправкой scheduler получает PostgreSQL advisory lock, проверяет log, отправляет, затем фиксирует external message ID. Повторный запуск безопасен.
