# 14. Накопительный табель

## Разделение

Каждый объект имеет отдельный табель. Общая сводка содержит только статус сдачи и верхнеуровневые суммы.

## Представление

Строки: категория + показатель + принадлежность/способ + единица. Колонки: каждый день периода. Справа: итог, среднее, максимум.

Персонал: итог = человеко-дни; среднее и максимум считаются по календарным дням, где ожидался отчёт. Техника, работы и грунт суммируются только внутри одинаковой единицы.

## Excel

Листы: `Общая сводка`, `Статус отправки`, по одному листу на объект, `Исходные отчёты`. Имя объектного листа строится из короткого code, очищается от запрещённых символов и ограничивается 31 символом.

Шапка и первые колонки закреплены, включён autofilter, нули отображаются пустыми, пропущенный обязательный отчёт отмечается отдельно от фактического нуля.

## Контрольные суммы

Экспорт должен повторять API timesheet. Тест создаёт минимум два дня, два объекта, две единицы и проверяет, что данные объектов и несовместимые единицы не смешались.
