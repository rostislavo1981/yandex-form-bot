## Шаг 0. Есть 3 минуты? Прочитай SUMMARY

**[`SUMMARY.md`](./SUMMARY.md) — сжатая картина всего пакета:** продукт, архитектура, модель данных, API, интеграция с MAX (сверенная с dev.max.ru/docs), план по фазам, все ADR, запреты, открытые вопросы.

## Шаг 1. За 10 минут пойми, что это за проект

Открой и прочитай (в этом порядке):

1. [`01_overview.md`](./01_overview.md) — что делаем и зачем (5 мин чтения).
2. [`02_architecture.md`](./02_architecture.md) — как устроено (10 мин).

После этого ты должен уметь ответить на вопросы:
- Что вводит пользователь? *(структурированные данные из справочников, не свободный текст)*
- Где хранятся данные? *(PostgreSQL, нормализованная схема)*
- Что связывает MAX и наш backend? *(бот в отдельном процессе + Mini App с HMAC-верификацией initData)*
- Что мы НЕ делаем в MVP? *(LLM, Playwright, Яндекс.Формы, Яндекс.Диск, админку, черновики, фото)*

Если не можешь — прочитай ещё раз.

## Шаг 6. Перед завершением сессии

**Обязательно:**

1. Прогнать `make lint && make test`. Оба должны быть зелёные.
2. Закоммитить изменения (`CONVENTIONS.md` → §Коммиты).
3. Обновить [`PROGRESS.md`](./PROGRESS.md):
   - Отметить закрытые задачи ✅.
   - Обновить «текущий шаг».
   - Добавить HANDOFF NOTE по [`HANDOFF_TEMPLATE.md`](./HANDOFF_TEMPLATE.md).
4. Если принял архитектурное решение — добавить запись в [`DECISIONS.md`](./DECISIONS.md).

## 🚫 Что запрещено

- **Не менять `01`…`10` без явной просьбы пользователя.** Это ТЗ, не черновик. Если реальность разошлась со спекой — сначала спроси, потом правь.
- **Не добавлять LLM (YandexGPT, OpenAI), Playwright, Яндекс.Диск, Яндекс.Формы** — это другой проект.
- **Не заменять PostgreSQL на SQLite** — нам нужны UNIQUE constraints и нормализация.
- **Не хранить секреты в git.** Только `.env` (который в `.gitignore`) и `.env.example` без реальных значений.
- **Не выдумывать параметры MAX API.** Если не подтверждено — помечай `[непроверено]` в коде и в комментарии.
- **Не переходить к следующей фазе, пока DoD текущей не выполнен.**
- **Не делать «улучшения» вне рамок текущей задачи.** Скоуп-крип запрещён.
