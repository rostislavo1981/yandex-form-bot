# AGENT START HERE

Эта инструкция специально написана так, чтобы агент с небольшим контекстом не потерял направление.

## Алгоритм работы

1. Прочитай `SUMMARY.md` полностью.
2. Прочитай верх `PROGRESS.md`: там ровно одна текущая итерация.
3. Открой эту итерацию в `08_implementation_plan.md`.
4. Прочитай только документы, указанные в поле «Читать».
5. Проверь `git status`; чужие изменения не трогай.
6. Реализуй только перечисленное в «Сделать».
7. Добавь тесты и выполни все команды DoD.
8. Если DoD не выполнен — остановись, запиши конкретный blocker.
9. Если выполнен — обнови `PROGRESS.md`, добавь handoff, один коммит.
10. Не начинай следующую итерацию без нового поручения.

## Приоритет источников

При конфликте:

1. Последнее явное сообщение пользователя.
2. `SUMMARY.md`.
3. `DECISIONS.md` со статусом accepted и более новым номером.
4. Нумерованные спецификации.
5. Старые HANDOFF NOTES.

## Запреты

- Не делать Bot-first и длинный опрос в чате.
- Не возвращать Яндекс.Формы, LLM, Playwright, Диск или SQLite.
- Не хранить справочники только во frontend/Excel.
- Не хранить табель широкими дневными колонками в БД.
- Не складывать разные единицы.
- Не использовать `window.MaxApp`; официальный объект `window.WebApp`.
- Не копировать старую Telegram-подобную HMAC-схему.
- Не придумывать MAX endpoint: сверить официальный docs в итерации интеграции.
- Не расширять текущую итерацию «полезными улучшениями».
- Не коммитить `.env`, токены, initData или raw персональные данные.

## Когда обязательно спросить пользователя

Только если невозможно продолжить безопасно: нет решения о домене/токене именно на production smoke; реальный MAX payload расходится с официальным контрактом; бизнес-правило меняет смысл expected report; обнаружены пересекающиеся чужие изменения.

Во всех остальных случаях следуй спецификации и делай маленький завершённый шаг.

## Handoff

Запись должна содержать: iteration, commit, сделано, не сделано, тесты с командами, blocker, следующий единственный шаг, изменённые файлы. Используй `HANDOFF_TEMPLATE.md`.
