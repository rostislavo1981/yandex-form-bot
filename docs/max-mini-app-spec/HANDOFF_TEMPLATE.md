# HANDOFF TEMPLATE

Добавить запись в верх раздела HANDOFF NOTES файла `PROGRESS.md`.

```md
### YYYY-MM-DD HH:MM — IXX завершена/заблокирована

**Агент:** модель
**Ветка:** имя
**Итерация:** IXX — название
**Коммит:** hash или «нет»

**Сделано:**
- конкретный результат

**Не сделано:**
- пункт и причина; либо «нет»

**Проверки:**
- `точная команда` → результат, N tests

**Blocker/риск:**
- конкретно; либо «нет»

**Следующий единственный шаг:**
- IYY, первое действие

**Изменённые файлы:**
- path
```

Запрещены формулировки «вроде работает», «почти готово», «оставил кое-что». Если DoD не выполнен, статус только `blocked`, следующая итерация не открывается.
