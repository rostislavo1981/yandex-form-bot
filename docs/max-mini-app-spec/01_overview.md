# 01. Обзор проекта

## Что делаем

Веб-мини-приложение, встраиваемое в мессенджер **MAX** (max.ru) через Bot API + Mini App API. Позволяет прорабу с телефона за 60 секунд сдать **ежедневный отчёт по строительному объекту**: дата, объект, этап, техника, работы, персонал, вывоз грунта.

Данные хранятся в PostgreSQL. Руководитель просматривает реестр отчётов и выгружает Excel.

## Зачем

Заменить Яндекс.Форму (медленную, с ручным вводом текстовых полей) на **структурированный ввод из справочников** прямо внутри чата MAX, где прораб уже находится.

## Основной сценарий (Happy Path)

1. Прораб пишет боту `/report` (или жмёт кнопку «📝 Отчёт» в меню).
2. Бот отвечает сообщением с inline-кнопкой «Открыть форму» (Mini App).
3. Открывается webview с формой:
   - дата (по умолчанию сегодня);
   - выбор объекта → подтягиваются этапы;
   - если объект подрядный — появляется поле «подрядчик»;
   - динамические строки «техника» и «работы»;
   - блок «персонал» — только для собственных сил;
   - поле «вывоз грунта, м³»;
   - комментарий.
4. Прораб жмёт «Отправить».
5. Backend валидирует, сохраняет в PostgreSQL, возвращает `{id, status}`.
6. Mini App закрывается, бот присылает подтверждение: `✅ Отчёт №42 принят`.

## Второй сценарий: сводная

1. `/summary` или кнопка «📊 Сводная».
2. Открывается вторая страница Mini App (или тот же webview с табом).
3. Показывает список отчётов за период (по умолчанию: сегодня + вчера).
4. Кнопка «📥 Excel» — скачивание xlsx.

## Роли пользователей

| Роль | Что может |
|---|---|
| `foreman` | Создавать свои отчёты, смотреть свой список |
| `manager` | Видеть все отчёты, качать Excel |
| `admin` | (пост-MVP) редактировать справочники |

В MVP различие ролей мягкое: все видят всё, но UI фильтрует «мои» по `max_user_id`.

## Границы MVP

### Входит
- MAX Bot (long polling) с командами `/start`, `/report`, `/summary`, `/help`.
- Mini App с формой отчёта и сводной.
- PostgreSQL + справочники (seed).
- HMAC-верификация `initData` из MAX.
- Excel-выгрузка (3 листа).
- Docker Compose для локали и VPS.
- HTTPS через Caddy/nginx на VPS (MAX Mini App требует HTTPS).

### Не входит (следующие этапы)
- Админка справочников через UI (пока — правкой в БД).
- Черновики, статусы, согласование.
- Фото/файлы.
- LLM-парсинг свободного текста.
- Заполнение чужих Яндекс.Форм.
- Webhook вместо long polling.
- Multi-tenant (несколько организаций).

## Что НЕ трогать

- Существующий проект `yandex-form-bot` (V1). Новый MVP — отдельный сервис, живёт рядом или заменяет постепенно.
- Реальные Яндекс.Формы. Мы их не заполняем.
- Playwright, YandexGPT, Яндекс.Диск. Их в MVP нет.
