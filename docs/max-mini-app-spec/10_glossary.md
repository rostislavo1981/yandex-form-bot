# 10. Глоссарий

| Термин | Значение |
|---|---|
| **MAX** | Российский мессенджер max.ru с Bot API и Mini App |
| **Mini App** | Webview, открываемое внутри MAX по кнопке в чате |
| **initData** | Подписанная строка, которую MAX кладёт в webview для проверки пользователя |
| **HMAC** | Keyed-Hash Message Authentication Code — способ проверки подписи |
| **Bot API** | HTTP-интерфейс для программного управления ботом |
| **long polling** | Способ получения обновлений: клиент делает длинный HTTP-запрос `getUpdates`, сервер держит его открытым до появления событий |
| **Webhook** | Альтернатива polling: MAX сам POST'ит обновления на наш URL |
| **Объект** | Строительная площадка с уникальным титулом (title_code) |
| **Титул** | Уникальный код объекта, напр. `БОГ-КЛ-04` |
| **Этап** | Стадия работ на объекте |
| **execution_method** | Способ выполнения работ: `own` (собственными силами) или `contractor` (подрядчиком) |
| **Собственные силы (own)** | Работы выполняются штатным персоналом организации |
| **Подрядчик (contractor)** | Работы выполняет подрядная организация |
| **snapshot-имя** | Копия имени справочной записи, сохранённая в момент создания отчёта (для истории) |
| **ИТР** | Инженерно-технические работники |
| **ОПР** | Основные производственные рабочие |
| **BootstrapContext** | React-контекст с закэшированными справочниками |
| **Bootstrap-запрос** | GET /api/bootstrap — единый ответ со всеми справочниками |
| **Динамические строки** | Ряды таблицы, добавляемые/удаляемые пользователем (техника, работы) |
| **DoD** | Definition of Done — критерий готовности фазы |
| **`[непроверено]`** | Пометка в спецификации: гипотеза, требующая подтверждения по официальной документации MAX |
