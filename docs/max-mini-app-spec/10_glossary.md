# 10. Глоссарий

| Термин | Значение |
|---|---|
| MAX | Мессенджер с Bot API и Mini App |
| Mini App | Webview, открываемое кнопкой `open_app` |
| `window.WebApp` | Официальный глобальный объект MAX Bridge |
| initData | Подписанная строка запуска, проверяемая backend двухступенчатым HMAC |
| Пульт | Сообщение с видимыми inline-кнопками; в группе закрепляется |
| Объект | Строительная площадка со стабильным коротким code |
| Этап | Справочная стадия, разрешённая для конкретного объекта |
| Assignment | Назначение ответственного на объект и период |
| Obligation | Ожидаемый отчёт: дата + assignment |
| Snapshot | Имя справочника, скопированное в отчёт для истории |
| Табель | Показатели по строкам, дни по колонкам, отдельно по объекту |
| Человеко-день | Сумма количества людей за каждый день периода |
| Idempotency key | Ключ, предотвращающий дубль при повторе запроса/job |
| DoD | Проверяемый критерий завершения итерации |
| Handoff | Короткая запись следующему агенту о результате и следующем шаге |
