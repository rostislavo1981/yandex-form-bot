# MAX Mini App «Ежедневный отчёт по объекту» — пакет спецификаций

Этот каталог — **самодостаточный пакет для разработки**. Любая модель, впервые открывшая его, должна за 5 минут понять, где остановились, что делать дальше и какие правила соблюдать.

---

## 🤖 Ты — модель, впервые открывающая пакет?

Три варианта в зависимости от бюджета времени:

- **3 минуты** — читай [`SUMMARY.md`](./SUMMARY.md). Один файл, вся картина.
- **10 минут** — читай [`AGENT_START_HERE.md`](./AGENT_START_HERE.md). Пошаговая инструкция как читать остальное.
- **Пишешь код** — [`AGENT_START_HERE.md`](./AGENT_START_HERE.md) → указанные там файлы → [`PROGRESS.md`](./PROGRESS.md) со свежей HANDOFF NOTE.

---

## 👤 Ты — человек, обзорно смотрящий пакет?

Читай [`SUMMARY.md`](./SUMMARY.md) — сжатая картина. Или продолжай оглавление ниже.

## Ключевые запреты (кратко)

- ❌ Не менять `01`…`10` без просьбы пользователя.
- ❌ Не добавлять LLM, Playwright, Яндекс.Диск, Яндекс.Формы.
- ❌ Не заменять PostgreSQL на SQLite.
- ❌ Не хранить секреты в git.
- ❌ Не выдумывать параметры MAX API (метка `[непроверено]`).
- ❌ Не переходить к следующей фазе, пока DoD текущей не выполнен.

Полный список в [`AGENT_START_HERE.md`](./AGENT_START_HERE.md) §«Что запрещено».
