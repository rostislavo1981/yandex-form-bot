# SUMMARY — окончательное ТЗ MVP

Актуальность: 2026-07-14. Этот документ имеет приоритет над более ранними handoff-записями.

## Продукт

Система ежедневной строительной отчётности внутри MAX:

1. Все ответственные состоят в одной рабочей группе MAX.
2. В группе закреплён видимый пульт с кнопками.
3. В личном диалоге с ботом также есть видимый персональный пульт.
4. Кнопка «Заполнить отчёт» открывает Mini App.
5. Пользователь выбирает объект, этап, технику и работы через поиск по динамическим справочникам.
6. После отправки краткая карточка отчёта публикуется в общей группе.
7. Вечером бот напоминает тем, кто не сдал отчёт.
8. Утром бот сообщает количество ожидаемых, отправленных и пропущенных отчётов и ФИО ответственных.
9. Главный результат — накопительный табель по каждому объекту с колонками по дням и суммами, доступный в Mini App и Excel.

## Выбранная архитектура

Один маршрут, без альтернативных треков:

- Mini App-first: React + TypeScript, мобильная форма с серверным поиском.
- FastAPI — API, MAX webhook и раздача собранного frontend.
- PostgreSQL — единственный источник истины.
- Отдельный scheduler-процесс из того же Python-пакета — обязательства, напоминания, утренняя сводка.
- Caddy — HTTPS.
- Excel — импорт/экспорт справочников и табелей, но не рабочая база данных.

Не входят в MVP: YandexGPT, Playwright, Яндекс.Формы, Яндекс.Диск, свободный текст как основной способ ввода, полноценная web-админка.

## Главные сущности

- Пользователи и роли.
- Рабочая MAX-группа и сохранённый ID закреплённого пульта.
- Объекты, этапы и связь объект–этап.
- Назначения ответственный–объект с периодом и графиком.
- Динамические справочники: подрядчики, единицы, техника, работы, способы работ.
- Ежедневные обязательства `дата + объект + ответственный`.
- Отчёт, строки техники, строки работ.
- Журнал уведомлений для защиты от дублей.
- Журнал импорта Excel.

## UX формы

- Ответственный определяется по MAX ID; подмена доступна только руководителю.
- Объекты ограничены назначениями пользователя и ищутся по коду, названию и псевдонимам.
- Этапы фильтруются по объекту.
- Техника: тип + принадлежность + единица + количество; строк можно добавить несколько.
- Работы: вид + способ + единица + количество; строк можно добавить несколько.
- Персонал: ИТР, штатные, внештатные.
- Вывоз грунта и комментарий.
- После успеха backend публикует карточку в общей группе.

## Табель

Табель строится отдельно по каждому объекту. Строки — показатели, колонки — дни, справа — итог, среднее и максимум.

Суммировать разрешено только одинаковые показатели с одинаковыми единицами. Персонал суммируется как человеко-дни; дополнительно показываются среднее и максимум за день.

Excel содержит листы `Общая сводка`, `Статус отправки`, отдельный лист на каждый объект и `Исходные отчёты`.

## Пульты MAX

Группа:

```text
[ 📝 Заполнить отчёт ]
[ 📊 Статус сегодня ] [ 📅 Табель ]
[ 📥 Excel ]          [ 👥 Кто не сдал ]
[ ℹ️ Помощь ]
```

Личный бот:

```text
[ 📝 Заполнить отчёт ]
[ 📋 Мои отчёты ] [ 📅 Мой табель ]
[ 🏗 Мои объекты ] [ 📥 Excel ]
[ ↩️ Рабочая группа ]
```

Команды `/start` и `/menu` остаются резервом, но пользователь не обязан помнить команды.
