# Yandex Form Bot

MAX-бот + YandexGPT + Яндекс Формы для ежедневных отчётов прорабов.

## Назначение

Прораб пишет в MAX свободным текстом отчёт о выполненных работах. Бот:
1. Парсит текст через **YandexGPT** в структурированный JSON
2. Заполняет **Яндекс Форму** (через Playwright MCP)
3. Сохраняет ответы на **Яндекс Диск** (накопительно)
4. По запросу выдаёт **Excel-сводную** по объектам × датам
